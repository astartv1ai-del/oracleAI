# Security — final-polish

## Threat model (изменённый скоуп)
Пасс не добавлял endpoint'ов, схем, интеграций. Векторы XSS/SQL не расширены:
- пользовательский ввод → `esc()` в miniapp, `?`-плейсхолдеры в repo
- dev_user закрыт DEV_MODE (см. security review от 2026-08-12)

## Решения
- Прод-деплой: `DEV_MODE=0` + строгий CSP — в runbook (см. devops/sre)
- Токены/секреты не затронуты; `.env` не трекается

## Остаточные риски (принять перед запуском)
1. Без строгого CSP miniapp уязвим к XSS при появлении неэскейпленного контента
   → mitigation: esc() на всех пользовательских полях, запретить inline-handlers (уже соблюдено)
2. Вход по подписи Telegram требует доверенного бота/секрета — провалидировать на проде
   (вне скоупа полировки)
