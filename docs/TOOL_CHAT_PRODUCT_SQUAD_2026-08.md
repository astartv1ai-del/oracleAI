# Product Squad: инструменты и чат OracleAI

**Статус:** активный план реализации  
**Дата:** 12 августа 2026  
**Цель:** довести каждый пользовательский инструмент и сам чат до уровня самостоятельного, понятного и эмоционально цельного мини-продукта для аудитории OracleAI.

> Каждый поток отвечает не только за внешний вид экрана. Его результатом считается законченный сценарий: понятный вход, безопасный сбор данных, интерактив во время выбора, ясная подача результата, следующий шаг, состояния загрузки и ошибки, а также доступность в Telegram WebApp.

## Общий контракт качества

| Область | Обязательное правило |
|---|---|
| Смысл и доверие | Не создавать ложную точность, не обещать предсказаний как фактов, объяснять ограничения данных человеческим языком. |
| Ввод | Каждое обязательное поле имеет label, причину запроса, допустимый формат и понятное продолжение при неполных данных. |
| Интерактив | Вибрация Telegram добавляется только к значимым действиям: выбору, раскрытию, подтверждению, успеху или ошибке. В браузере сценарий остаётся полностью рабочим без неё. |
| Motion | Анимации используют только `transform` и `opacity`, укладываются в 100–300 мс для частых действий и отключаются при `prefers-reduced-motion`. |
| Доступность | Интерактивные элементы доступны тапом и клавиатурой, не конфликтуют с вертикальным скроллом и не требуют точных жестов. |
| Надёжность | Для каждого сценария обязательны loading, empty, error и recovery-состояния без вывода технических API-деталей. |
| Архитектура | Изменения не дублируют сетевые вызовы, используют текущий action registry, единый haptic-адаптер и существующие API-контракты. |

## Рамка приоритизации

Сначала выполняются дефекты, которые блокируют сценарий, и улучшения, которые повышают понятность самого первого действия. После этого добавляются управляемые сенсорные и визуальные эффекты. Новый элемент не принимается, если он выглядит эффектно, но скрывает действие, увеличивает когнитивную нагрузку или ухудшает режим reduced motion.

## Критерии интеграционного приёма

| Проверка | Критерий |
|---|---|
| Путь из чата в инструмент и обратно | Не теряется активный проводник, черновик вопроса и возможность вернуться одним действием. |
| Haptics | В Telegram срабатывает один уместный сигнал на действие; в браузере отсутствуют ошибки при недоступном API. |
| Свайпы | Не перехватывают ввод, скролл, `details`, карусели и внутренние интерактивные элементы. |
| Первый запуск | Guide показывается деликатно, запоминается локально и не блокирует доступ к основным функциям. |
| Quality gates | Синтаксис JavaScript, `pytest`, `git diff --check`, browser smoke ключевых потоков и console review проходят без ошибок приложения. |
