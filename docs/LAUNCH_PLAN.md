# План запуска (G37): каналы-спутники, листинги, механика

Каналы-спутники в коде **готовы**: `app/services/horoscopes.py` — `post_day`
постит общий гороскоп знака в каналы из `settings.horoscope_channels`
(формат `Овен:@oracle_oven, Телец:@oracle_taurus, …`), включается флагом
`horoscope_channels`. Золотые билеты (промокоды в PDF, §7.2) тоже на месте.
Осталось — настроить и запустить.

## 1. Каналы-спутники (за 2 недели до запуска)

1. Создать в Telegram 12 знаковых каналов или один канал «Оракул · Гороскоп
   дня» с разбивкой по темам. Бот должен быть администратором.
2. В `.env.production`: `HOROSCOPE_CHANNELS="Овен:@oracle_oven,..."` и флаг
   `horoscope_channels` ON в админке.
3. Проверить `post_day` вручную одной командой (панель → инструменты или
   `python -m app.services.test`), затем доверить планировщику.
4. Контент-план на первые 4 недели: посты «карта дня», редкие разборы
   (витрина качества), кейсы «что было написано в прогнозе — и случилось».

## 2. Листинги (за неделю)

- **BotFather**: `/setname`, `/setdescription`, `/setabouttext`, `/setuserpic`,
  `/setcommands` (справка уже в боте), `/setinline`.
- **Библиотека Telegram-ботов** (store.telegram.org «Боты» → предложить,
  если доступно) и каталоги мини-приложений (@BotList, каталоги WebApps).
- **@BotFather → /mybots → опубликовать в каталоге** при наличии категории
  «гороскопы/развлечения».
- Поставить ссылки: сайт → бот, канал → бот, лендинг (G36) → бот.

## 3. Механика первого трафика

- **Рефералка**: уже в продукте (таблица `referrals`, бонусы ✦).
- **PDF-маркетплейсы**: 2–3 разбора с «золотыми билетами» (промокод
  = 30-дневный триал) — теплый трафик, CAC ≈ себестоимость разбора.
- **Спутники**: перелив подписчика канала → бот через кнопку прогноза.
- **Сегментация рассылок** (админка): winback по `expiry_notified`, апселл
  guide → vip, активация триала.

## 4. KPI первого месяца (целевые)

- Активация: ≥ 60% дошедших от /start до первого прогноза.
- Активация платных: trial → paid ≥ 5% выбравших промокод; конверсия
  витрины ≥ 2% на активных.
- Ретеншен: D7 ≥ 25%, D30 ≥ 12% (вилка из ТЗ §2 для ниши).
- Стоимость: CAC < LTV/3 (см. docs/UNIT_ECONOMICS.md).

## 5. День запуска

1. Selfcheck: `python scripts/selfcheck.py` — 0 ошибок.
2. `pytest` — зелёно.
3. Боевой VPS: деплой (compose up), проверить /api/health, канал-спутник
   постит, бот отвечает /start.
4. Флаг DEV_MODE=0, включить UptimeRobot, Sentry DSN задан.
5. Первое подписное объявление в канале-спутнике + пост-анонс в личный.
