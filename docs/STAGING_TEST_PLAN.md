# Ручной тест-план на staging (G30)

Прогон живым человеком на staging за 1–2 дня до запуска. Staging — отдельный
инстанс (та же `infra/docker-compose.yml`) с **тестовым ботом-дубликатом** и
`DEV_MODE=1`. Результаты ставить в графу «✓»; любой сбой — завести тикет и не
выкатывать прод до закрытия.

Перед началом: поднять compose, проверить `GET /api/health` (ok), ввести
`ANTHROPIC_API_KEY`/`OPENAI_API_KEY` тестового бота, прогнать
`python -m scripts.selfcheck` (все ✅).
