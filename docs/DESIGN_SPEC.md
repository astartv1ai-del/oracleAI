# Оракул — Дизайн-спецификация продукта

> **Статус:** v2.0 (Astral Midnight · chat-first) · **Формат:** живой документ, ведётся вместе с кодом
> **Платформы:** ПК (Mini App в Telegram Desktop + Web) · Мобайл (iOS/Android)
> **Аудитория:** русскоязычные женщины 25–45, личный AI-астролог
> **Реализация:** `miniapp/styles.css` + `miniapp/app.js` — каждый токен и компонент ниже
> имеет прямое отражение в коде.

Документ описывает **полный продуктовый дизайн**: от дизайн-системы и визуального
языка до архитектуры фронтенда и состояний. Это не «макет», это рабочая
договорённость между дизайном и кодом.

---

## 0. Резюме одной страницей

**Продукт** — личный AI-астролог в концепции **chat-first**. Не «бот-говорилка», а
проводник: честные расчёты (Swiss Ephemeris, Таро, Матрица Судьбы), которые ИИ трактует
на живом русском. **Чат — главный инструмент:** экраны — лёгкая рамка вокруг диалога
с агентом, а функции (расклад Таро, натальная карта, лунная неделя) живут кнопками
прямо в диалоге.

**Визуальная идея — «Astral Midnight».** Тёмно-индиго космос с тёплым золотом и
аметистом, glassmorphism, звёздное небо, 3D-переворот таро-карт. Премиум строится на
калибровке: глубокий ночной фон, благородное золото, аметистовая подсветка, редакционная
типографика, воздух. Мистика — в **точности расчёта**, а не в картинках.

**Три правила больших данных** (отвечают на боль про «супер-длинную страницу»):

1. **Одно главное число на экран** — глаз ловит ядро, остальное многоуровнево.
2. **Прогрессивное раскрытие** — заголовок-цифра → раскрыть → детали.
3. **Функции — в диалоге** — нет простыни экранов, есть чипсы и виджеты в чате.

---

## 1. Принципы (не обсуждаются)

1. **Честность расчёта = достоинство.** Дома, градусы, аспекты, фазы подаём как
   точные данные. Чем точнее цифра — тем «дороже» выглядит. Декор не заменяет расчёт.
2. **Два акцента.** Золото — для смысла и чисел (крупно, точками и линейками, никогда
   заливкой); аметист — для магии и подсветки. Акценты — точки свечения, не плашки.
3. **Воздух — это роскошь.** Больше пустоты, чем контента на экран управления.
4. **Продукт не навязывает.** Лимиты и монетизация — мягкие карточки, не «дверь в лицо».
5. **Данные сдаются в сетку, а не в абзац.** Числа живут в колонках, не в прозе.
6. **Чат — приоритет.** Интерфейс не конкурирует с диалогом: рамка тихая, агент громкий.

## 2. Визуальный язык

### 2.1 Дизайн-токены (тёмная тема — единственная на старте)

Палитра **Astral Midnight**: глубокий космос (`#08070f`), индиго-поверхности, тёплое
золото и аметист, полупрозрачное стекло. Все значения — реальные CSS-переменные
`miniapp/styles.css`.

| Токен | Значение | Назначение |
|---|---|---|
| `--bg-0` | `#08070f` | основной фон, «ночной космос» |
| `--bg-1` | `#0e0d1e` | подложка шапок, градиенты |
| `--bg-2` | `#151330` | модалы, вложенные блоки |
| `--glass` | `rgba(24,22,48,.55)` | glass-карточки + `backdrop-blur` |
| `--glass-strong` | `rgba(28,26,56,.72)` | пузыри агента, навбар |
| `--gold` | `#e6c178` | золото-якорь: числа, заголовки, кайма |
| `--gold-bright` | `#ffd98f` | светлое золото: активное, имена |
| `--gold-deep` | `#b98946` | тень золота, градиенты кнопок |
| `--gold-glow` | `rgba(230,193,120,.35)` | золотое свечение |
| `--violet` | `#a78bfa` | аметист: подсветка, магия |
| `--violet-glow` | `rgba(167,139,250,.35)` | аметистовое свечение |
| `--text` | `#f4f1ff` | основной текст, светлый |
| `--text-dim` | `#a49cc8` | подписи, meta (≥4.5:1 на фоне) |
| `--text-faint` | `#6f6890` | декоративный/необязательный |
| `--border` | `rgba(190,170,255,.13)` | hairline-границы |
| `--border-strong` | `rgba(230,193,120,.42)` | золотая кайма акцентов |
| радиусы | `14 / 20 / 28px` | `--r-s / --r-m / --r-l` |
| тень карт | `0 18px 50px -18px rgba(0,0,0,.85)` | `--sh-card` |
| тень золота | `0 0 0 1px gold·06 + 0 18px 50px -22px gold·18` | `--sh-gold` |
| easing | `cubic-bezier(0.22, 1, 0.36, 1)` | `--ease`, все движения |

**Правило золота (критично):** золото — акцент крупного и светящегося. Мелкий текст —
`--text`/`--text-dim` (светлый), НИКОГДА золотом. Золото применяется к: дисплейным
числам и именам, каймам (`border-strong`), фокус-кольцу, свечению (`glow`), иконкам.
Аметист — к подсветкам (`violet-glow`), конic-кайме кольца агентов, акцентам магии.

Контраст выдержан: текст ≥4.5:1, крупный текст и иконки ≥3:1.

### 2.2 Типографика — двигатель премиальности

| Роль | Семейство | Замечание |
|---|---|---|
| **Дисплей** (заголовки, имена, числа) | **Cinzel** (500/600/700, кириллица) | античный serif, капитель, буквенная разрядка |
| **Тело** | **Plus Jakarta Sans** (400–800) | гуманистический гротеск, читаемость |
| **Числа/градусы** | табулярные (`font-variant-numeric: tabular-nums`) | «банковские» цифры без моношрифта |
| **Meta/eyebrow** | капс + `letter-spacing` 2px, размер 10–12px | подписи дат, секций |

Подключение — **самохостинг** под строгий прод-CSP (`style-src 'self'`):
woff2 лежат в `miniapp/fonts/` (Cinzel + Plus Jakarta Sans, кириллица и unicode-range
сохранены из Google Fonts), подключены через `oracle-fonts.css`; ассеты с cache-busting `?v=1`. Заголовки секций — Cinzel капителью с буквенным трекингом, «сегодня» —
gradient-text золото→аметист.

### 2.3 «Один решительный флориш»

**Звёздное небо** (`.starfield`) — единственный повторяющийся фон-приём: фиксированный
слой с радиальными градиентами (индиго-верх, аметист-низ) и дрейфующими звёздными
точками (золотые, белые, аметистовые), две слои анимации `starDrift` 90/140s в разные
стороны. Поверх — glass-интерфейс. Никаких россыпей эффектов сверх этого.

### 2.4 Графика

Дефолт — эмодзи-глифы агентов и карт (данные приходят с бэкенда) + стилизованные
орбы-градиенты. Реалистичные изображения — только точечно. Иконки — line-style;
аватары агентов — радиальные градиенты с каймой accent-цвета (`::before` mask-composite).
Никаких wireframe-боксов.

## 3. Компонентная система

### 3.1 Базовые

- **Glass-карточка** (`.glass`) — `rgba`-заливка + `backdrop-filter: blur(10px)` +
  `border 1px` + `border-radius 20px` + мягкая тень `--sh-card`. Акцентная — `.glow-border`
  с градиентной каймой золото→аметист (mask-composite xor). Наведение — подъём и уточнение каймы.
- **Button** — `.btn-primary` (золотой градиент `gold-bright→gold-deep`, тёмный текст,
  свечение `--sh-gold`) и `.btn-ghost` (hairline + светлый текст). Высота ≥44px, тач-область ≥44px.
- **Input / Textarea** (`.ipt`) — тёмная подложка `rgba(10,9,22,.6)`, hairline-кайма,
  фокус: золотая кайма + кольцо `--gold-glow` (≥3:1). Плейсхолдер — `--text-faint`.
- **Feature-чипс** (`.chip`) — капсула: эмодзи + текст, hairline, hover → accent-кайма.
  Живёт в хабе агентов и в полосе фич чата. Виды: `chip` (действие), `suggest-chips` (подсказки).
- **Spread-ячейка** (`.spread-cell`) — выбор схемы расклада в чат-виджете; `.premium` —
  золотой текст + 🔒; `.sel` — золотая кайма + свечение.
- **Card-day** — карточка «карта дня»: вертикальная мини-карта с золотой каймой.
- **Stat** — ячейка статистики профиля: табулярное число золотом + подпись.
- **Result-card** — карточка результата (расклад/разбор): заголовок serif + meta, hover — сдвиг.
- **Modal** (`.modal-overlay`/`.modal`) — затемнение `blur(6px)` + стеклянная панель,
  появление `popIn`. Используется для чтения расклада и разбора.
- **Skeleton** — shimmer-пульс в тон фона (не спиннер).
- **Badge-dot** — золотая точка-уведомление с glow.

### 3.2 Компоненты chat-first

- **Кольцо агентов** (`agent-dock`) — на «Сегодня»: орбы-аватары с conic-каймой
  золото→аметист (`mask-composite: xor`), hover — подъём + аметистовое свечение.
- **Карточка агента** (хаб): аватар с accent-каймой, имя serif, роль accent-цветом,
  превью `last_text` (ellipsis) + **полоса фич-чипсов**.
- **Чат-виджет** (`.chat-widget`) — системное сообщение-форма внутри ленты: заголовок
  serif золотом + содержимое фичи (расклад, натальная карта, форма совместимости).
- **Пузыри сообщений** — клиентка: золотой градиент + тёмный текст, скругление
  `18px 18px 5px 18px`; агент: `--glass-strong` + hairline, `18px 18px 18px 5px`.
- **Таро-карта** (`.tarot-card`) — 88×136, 3D-переворот 700ms (см. §5.1); рубашка —
  индиго-градиент + золотая кайма + мотив «☾ ORACLE».
- **Hero «Сегодня»** (`.hero-orb`) — высокая карта с плавающей золото-аметистовой орбой
  (`orbFloat` 8s), дата капсом, приветствие serif, строка Луны.

### 3.3 Паттерн «цифра → раскрытие»

Универсальный решатель «длинной страницы»:

```
[ Солнце · Дом VII · 12° ♌ ]      ← строка-сводка, кликабельна
        ▼ раскрыть
[ детали: управитель, аспекты,    ← аккордеон
  трактовка в 1 абзаце ]
```

В chat-first применяется в виджетах (карта, расклад) и Профиле. Правило:
**в свёрнутом виде одно число/одна строка; раскрытие — по запросу.**

### 3.4 Паттерн «одно главное число»

На «Сегодня» — ядро дня (прогноз + карта дня) крупно вверху. Всё остальное —
второстепенные виджеты ниже. Глаз не сканирует простыню — он ловит ядро.

## 4. Навигация и информационная архитектура

**4 экрана** (нижний таб-бар `app-nav`, максимум 480px):

| Экран | Главная цель | Ключевые элементы |
|---|---|---|
| **Сегодня** | ядро дня за 5 сек, статичная база | hero-орба, прогноз, карта дня, кольцо агентов |
| **Агенты** | выбор собеседника | карточки агентов + фичи-чипсы |
| **Чат** | главный инструмент | шапка, полоса фич, лента, композер, чат-виджеты |
| **Профиль** | хранилище результатов | статистика, натальная карта, расклады, разборы, память |

Функции бывших отдельных экранов (Таро, Карта, Практики, Дневник, Лавка) живут
**фичами в диалоге** и результатами в Профиле. Единый якорь-флориш — звёздное небо и
золото-аметистовое свечение в одной тональности на всех экранах.

**Запоминание:** анкор-экран «Сегодня» — узнаваемое «лицо» продукта (hero + карта дня);
остальные экраны — спокойная рамка, чтобы диалог оставался главным.

## 5. Состояния и ошибки (часть дизайн-системы)

У каждого виджета/списка 5 состояний: **loading · empty · error · data · edge**.

- **Loading** — скелетон в тон фона (shimmer-пульс) или loader-ring; НЕ спиннер-вращалка.
- **Empty** — фирменная пустота: «Здесь пока тихо», 1 строка подсказки, CTA
  (например, «Собери карту у Астролога — прямо в чате»).
- **Error** — что случилось + что делать + retry с бэкоффом 2/4/8с, затем
  «Связаться с поддержкой» + ID.
- **Data** — наполнение по паттернам §3.
- **Edge** — перенос строк, усечение с многоточием, `overflow-wrap`, проверка RTL.

**Reduced motion:** `prefers-reduced-motion` → убрать трансляции/перевороты, оставить
кроссфейды. Фокус: `:focus-visible` с золотым кольцом, контраст ≥3:1.

## 6. Микроинтерфейс и тон

- **Переходы между экранами** — кроссфейд 200–300ms, без слайдов-спрингов.
- **Чат-виджеты** — появление `msgIn` (fade + подъём 8px, 350ms), staged для пузырей.
- **3D-переворот Таро** — единственное место, где допускается «театр» (700ms);
  с `prefers-reduced-motion` → мягкий кроссфейд.
- **Наведение на карточку** — подъём 1–2px + уточнение каймы, 150ms; чипс — подсветка accent.
- Звук — нет (астрогештальт, без аудио-декора).

Тон текста: тёплый, таинственный, но без манипуляций. «Время рождения неизвестно»
подаётся как доверие, а не как укор.

## 8. Архитектура и стек (фронтенд)

### 8.1 Стек (фактический)

**Vanilla JS + CSS, без сборки.** `miniapp/` отдаётся FastAPI как статика
(`/static` → `miniapp/`, StaticFiles): `index.html` + `styles.css` + `app.js`.
Одиночный объект `window.app` с методами-экранами и реестром фич. Причины:

- Гринфилд уже реализован: 4 экрана + чат-виджеты на vanilla — просто и предсказуемо.
- Нет билд-стадии — нет гонки деплоя ассетов и npm-стадии в Docker.
- **`@twa-dev/sdk` — НЕ нужен.** Авторизация серверная: `X-Init-Data` (HMAC по `bot_token`).
  Клиенту нужен лишь `Telegram.WebApp.initData`, который Telegram впрыскивает сам.
- Если интерфейс вырастет (полное SVG-колесо, октаграмма, спидометр) — кандидаты:
  нативный SVG; фреймворк подключать только при явной необходимости.

### 8.2 Сборка и хостинг

Без сборки: `index.html` подключает `/static/fonts/oracle-fonts.css`, `/static/styles.css`
и `/static/app.js` (с `?v=1`); шрифты — локальные woff2 из `miniapp/fonts/` (прод-CSP
не пускает сторонние стили); `telegram-web-app.js` — официальный скрипт Telegram. Корень FastAPI плотно занят роутами — ассеты под `/static/`.

### 8.3 Структура

```
miniapp/
├── index.html      # каркас, telegram-web-app.js, .starfield, cache-busting ?v=1
├── styles.css      # дизайн-система Astral Midnight (токены + компоненты)
├── fonts/          # самохостинг шрифтов: oracle-fonts.css + woff2 (Cinzel, PJS)
└── app.js          # chat-first приложение: api-клиент, реестр FEATURES,
                    # экраны (home/hub/chat/profile), чат-виджеты;
                    # 0 inline-хендлеров — делегирование data-act + rich()-экранирование
```

### 8.4 Данные из API

- Экраны ↔ эндпоинты FastAPI, формат JSON; ошибки — `{detail}`.
- **Свёрнутые данные приходят свёрнутыми** (§3.3) — детали lazy-запросом.
- Клиент — тонкая обёртка `fetch` с заголовком `X-Init-Data` (§2 FRONTEND_TZ).

### 8.5 Бэкенд-стык (уже есть)

FastAPI + встроенный веб; монетизация: триал 30дн → «Искра»; лимиты «пламя» +
экстренный вопрос за Кристаллы ✦; 6 агентов (oracle/tarot/astro/coach/numero/keeper);
честные расчёты (Swiss Ephemeris, Таро, Матрица Судьбы) — душа, которую интерфейс
бережно показывает.

## 9. Дорожная карта сборки

1. **Реализовано:** токены и палитра Astral Midnight; типографика (Cinzel × Plus Jakarta
   Sans); каркас (шапка, таб-бар, звёздное небо); экраны «Сегодня», «Агенты», «Чат»,
   «Профиль»; чат-виджеты (Таро с 3D-переворотом, натальная карта, луна, матрица,
   совместимость, прогноз, история).
2. **Фаза состояний:** полный прогон loading/empty/error/edge у всех виджетов + retry-бэкофф.
3. **Фаза премиум:** пейволл-карточка в чате, лавка, «сбылось», сторис, практики/дневник
   фичами, полное SVG-колесо, октаграмма, спидометр, стрик.
4. **Фаза polish:** reduced-motion, фокус, микроанимации, аудит контраста.

**Критерий «выглядит дорого»:** одновременно выполнены (а) одно главное число,
(б) воздух, (в) золото только точками и свечением, (г) табулярные цифры,
(д) ни одной золотой заливки и ни одной «дешёвой» звёздной картинки (только `.starfield`).

## 10. Глоссарий

- **Пламя** — геймифицированный лимит вопросов; мягкая карточка, не блок.
- **Кристаллы ✦** — валюта для экстренных вопросов и покупок.
- **Искра** — бесплатный план «карта дня + вопрос/нед».
- **Hairline** — граница 1px высокой точности, «золото точками» в линиях.
- **Glassmorphism** — полупрозрачные поверхности `backdrop-blur` над звёздным небом.
- **Фича-чипс** — кнопка-функция агента в диалоге (см. FRONTEND_TZ §4.3).
- **Astral Midnight** — дизайн-система: космос + золото + аметист.
