P1 blockers before public launch

OPEN
Capacity / SQLite ceiling
Approved load profile, p50/p95/p99, SQLite ceiling and scale decision.
PARTIAL
Payment sandbox certification
Provider sandbox signed webhooks, duplicate/out-of-order, refund/restore/reconciliation.
OPEN
Support readiness and SLA
FAQ, response templates, deletion/privacy/payment/safety escalation paths, named support owner.
OPEN
Privacy-safe funnel and cohort analytics
Event dictionary implementation from landing to first value, D1/D7 cohorts, cost and conversion.
PARTIAL
Accessibility / device acceptance
Touch target, keyboard/focus, screen reader, contrast/WCAG AA, reduced motion, Telegram safe area.
OPEN
Two controlled beta waves
Invite-only beta waves with capped traffic, feature flags, release owner, stop conditions.
OPEN
Canary, rollback and 72-hour rota
Versioned release, backup confirmation, canary, feature flags, rollback command, migration rehearsal.
A green unit-test suite alone cannot close these gates.
