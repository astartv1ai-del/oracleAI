# Возврат космического фона — решение

**Дата:** 12 августа 2026  
**Статус:** выбран для интеграции

Для глобального фона OracleAI выбран существующий ассет `miniapp/img/bg-cosmos.jpg` размером 872×1300. Это портретная композиция со звёздными контурами, фиолетовой туманностью в верхней части и холодным свечением слева внизу. Она лучше подходит для мобильного Mini App, потому что сохраняет выразительную вертикальную историю и достаточно тёмные зоны для текста.

Второй существующий ассет `miniapp/img/bg-cosmos-2.jpg` размером 1300×1300 будет использоваться как мягкий дополнительный слой для широких экранов, где квадратная композиция заполняет края без растягивания портретного изображения.

| Требование | Решение |
|---|---|
| Читаемость | Добавить постоянный затемняющий градиент над изображением; непрозрачные и полупрозрачные поверхности интерфейса остаются самостоятельными. |
| Производительность | Использовать только существующие локальные JPEG, без новых сетевых запросов и анимирования `background-position`. |
| Поведение на мобильном | Фон фиксируется за приложением и масштабируется через `cover`; ключевой центр композиции смещается к верхней трети. |
| Доступность | При `prefers-reduced-motion` отключать только декоративное мерцание звёзд, статичное фоновое изображение сохранять. |
| Поверхности | Чат, формы и нижняя навигация получают glass-слой, который отделяет контент от космоса, но не скрывает атмосферу. |
