# FE_CODE_STYLE.md — кодстайл фронтенда «Оракул»

Фреймворка и сборщика НЕТ. Чистый vanilla JS + CSS, раздача статикой FastAPI `/static`. Любой новый файл в `miniapp/` доступен по `/static/...`.

## JS

### Нейминг
- **Методы приложения** — camelCase, глагол: `openChat`, `toggleToolbox`, `careerDay`, `filterElement`. Это всегда методы единого объекта `window.app`, не свободные функции.
- **Top-level хелперы** — camelCase существительное/глагол: `esc`, `api`, `haptic`, `fmtDate`, `toRoman`, `planetGlyph`, `spreadScheme`.
- **Константы-объекты** — UPPER_SNAKE: `FEATURES`, `TEMPLATES`, `SIGNS`, `SIGN_ELEM`, `PLANET_GLYPH`.
- **CSS-классы/id/`data-act`** — kebab-case, меняются согласованно в JS и CSS.

### Переменные
- `const` по умолчанию. `let` только для переприсваивания. `var` — никогда.
- Строгие сравнения `===` / `!==`. Проверка пустоты: `== null` (покрывает null и undefined), не `!value` там, где 0/'' валидны.
- Пустые проверки API-ответов: `(r && r.items) || []` — фоллбэк на пустой массив, рендер не падает.

### DOM и безопасность
- **Никаких inline-обработчиков** (`onclick`/`oninput` в HTML) — запрет прод-CSP. Вся интерактивность через `data-act="имя"` + один делегирующий слушатель на документе (см. `FE_ARCHITECTURE.md`, модуль 13-events).
- **Экранирование**: любая вставка пользовательского/LLM-текста в HTML — через `esc()`, формат LLM-разметки `**bold**`/`*italic*` — через `richMd()`. Никогда не вставлять сырой текст в шаблонные строки.
- HTML строится шаблонными строками `` ` `` и вставляется `.innerHTML =`. Недопустимо собирать HTML конкатенацией без экранирования.

### Хелперы (обязательные)
- `esc(s)`, `rich(s)`, `richMd(s)` — экранирование/лёгкая разметка.
- `api(path, opts)` — обёртка fetch, JSON, авто-retry и токены.
- `haptic(kind)` — тактильный отклик Telegram.
- `navigator.vibrate(...)` — короткие вибрации прямо в экшенах (10–30ms), обёрнутые в `try/catch`.

### Состояние
- Всё состояние приложения — поля единого объекта `app` (`app.state`, `app.view`, `app.chat`). Методы читают/пишут только его, глобальных синглтонов не плодить.
- Приватные данные экрана (`chat.pending`) — объект с `kind`, `loading`, `data`. Рендер смотрит `p.kind`.

### Идиомы
- Условные ранние выходы: `if (!p || p.kind !== 'matrix' || !p.data) return;`
- Один экран — один рендер-метод, возвращает HTML-строку или ставит `.innerHTML` в переданный контейнер.
- Комментарии — только «почему», не «что». Однострочные `//` или блок `/* */` для неочевидных вещей.

## CSS

### Нейминг
- Селекторы — kebab-case: `.chat-widget`, `.moon-week`, `.modal-overlay`.
- Префиксы по назначению виджета: `nw-` (наталка), `spd-` (спидометр), `el-` (стихии), `cg-` (чат-гайд), `te-` (тулбар), `.msg`, `.pw-`.
- Состояния — суффиксы: `.on`, `.active`, `.open`, `.flipped`, `.fresh`.

### Токены
- Никаких «магических» значений цветов/радиусов/теней в правилах — только переменные из `:root` (`css/00-tokens.css`): `--gold`, `--violet`, `--text`, `--r-m`, `--sh-card`, `--ease` и т.д. Хардкод допустим только для редких локальных штампов (например, анимации задержек), иначе — токен.
- Полный список токенов: `FE_DESIGN_TOKENS.md`.

### Структура файла
- Каждый файл — одна тема (секция), шапка `/* ── тема ── */` (или `/* ===...=== */` для крупных блоков).
- Порядок секций = порядок каскада. Поздний файл переопределяет ранний. Новые переопределяющие правила кладутся НИЖЕ по этому порядку (в `css/14-widgets.css` или ниже).
- Высота: держать свои стили изолированными от других виджетов, селекторы не цеплять чужие классы.

### Каскад и подключение
- Единая точка подключения — `miniapp/styles.css`, только `@import url('css/NN-name.css');` первыми строками, по порядку. В нём не пишут правила.
- Новый css-файл = новая строка `@import` в конце списка.
- Индексация файлов: `NN-` (00..14) задаёт порядок в `@import`.

## index.html
- Вид базовой страницы: не менять разметку шапки/`#app-root`. Кэш-бастинг — `?v=N` в href: при любой правке js/css поднять `N` на `+1` во всех ссылках одновременно.
- Новый скрипт подключается `<script src="/static/js/NN-name.js?v=N">` перед модулями, от которых зависит.
