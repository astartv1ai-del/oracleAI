# FE_DESIGN_TOKENS.md — дизайн-токены (Astral Midnight)

Живут в `miniapp/css/00-tokens.css`, блок `:root`. Единственный источник цветов/радиусов/теней/шрифтов. Новые стили обязаны использовать токены, а не хардкод.

## Геометрия

|---|---|---|

| `--r-m` | `20px` | Средний (карточки, модалы) |

## Тени и анимация

| Токен | Значение | Назначение |
|---|---|---|
| `--sh-card` | `0 18px 50px -18px rgba(0,0,0,.85)` | Тень карточек |
| `--sh-gold` | `0 0 0 1px rgba(230,193,120,.06), 0 18px 50px -22px rgba(230,193,120,.18)` | Золотистая тень (акцент) |
| `--ease` | `cubic-bezier(.22,1,.36,1)` | Стандартная кривая анимации |

## Темы
- HTML несёт `data-theme="dark"` (index.html `lang="ru" data-theme="dark"`). Селекторы темным вариантам — `[data-theme="..."]` в `00-tokens.css` при их появлении.

## Правила применения
1. Цвет фона поверхностей: `--bg-0` → `--bg-1` → `--bg-2` по иерархии.
2. Акценты: золото — первичное действие/актив, аметист — второстепенное/информация.
3. Радиусы только из `--r-*`; отступы — кратные сетке (4px и его множители).
4. Тени только из `--sh-*`; новую тень сначала добавить токеном.
5. Анимации — `--ease`, короткие (150–300ms), не более 400ms на модал.
6. Свечения `--*-glow` — через `box-shadow` или `drop-shadow`, не отдельными blur-элементами.
