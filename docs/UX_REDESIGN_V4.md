## 1.7. Таро v4.6 — школа/колода подтверждены, карта дня на RWS, компактный выбор, LLM-гайд

**Пункты запроса (5):**

Фикс: `white-space: normal` на `.chat-widget`, карточки `.spread-card` → flex-column, свайпу задана компактная высота `150px`. Итог: виджет выбора **367px** (было 763), `fits:true` на 375×812. Плюс fallback-описания `s.hint || s.desc`.
2. **Какая колода/школа.** Скачаны картинки **Pam-A Rider–Waite** (метаданные Commons подтверждают: «Pamela Colman Smith»), школа **Rider-Waite-Smith (RWS)**. Порядок старших сходится (Сила VIII / Правосудие XI — `m08`/`m11`). Значения в бэке (`RWS_MINOR`, majors) — по Уэйту. Все 78 слагов совпадают с файлами (0 missing, 0 дублей).
3. **Карта дня — та же колода.** `/api/today` теперь отдаёт `card.img`; front-лицевая карта дня — реальная RWS картинка (`m21` Мир), имя под картой (дуга-имя убрана). Переворот раскрывает смысл.
4. **Имя+описание — только при открытии.** `.tpos-mean`/`.tpos-desc` скрыты (`display:none`), показываются по `.open` (после флипа). Проверено: до — `none`, после — `block`.
5. **LLM и школа.** `TAROT_GUIDE` в `app/core/skills.py` переписан по литературе RWS (Waite, Greer «Tarot Reversals», Pollack): школа и символика, архетипы 22 старших, масти=стихии, числа 1-10, двор, перевёрнутые по Грир (блок/сдвиг внутрь/тень, не «плохо»), связка в сюжет, этика. ## 1.6. Таро v4.5 — колода Rider-Waite и компактный расклад (решение + сделано)

**Исследование (внешние референсы):**
- **Наша система:** 78 карт в `app/core/tarot.py` (`full_deck`): 22 старших (эмодзи+смысл) + 56 младших (`rank suit`, RWS_MINOR). В draw-ответе карты получали только `emoji/name/meaning/reversed` — **без картинок**.
- **Ссылки из запроса:** `tarotoo-mcp-server` — текстовые значения RWS (MIT), картинок не отдаёт; `kaggle tarot-json` — те же сканы RWS (MIT), без URL картинок; **Wikimedia Commons — полный набор RWS, public domain** (Pamela Colman Smith, 1909), соглашение имён: старшие `RWS_Tarot_00_Fool.jpg`…`21_World.jpg`, младшие `Suit01..14.jpg` (01=Ace…10, 11=Page…14=King, Пентакли=`Pents`).
- **Решение:** селфхостим 78 картинок RWS 320px (`miniapp/img/tarot/{slug}.jpg`, ~7.2MB) — CSP `img-src 'self'` не блокирует; описание пишется ПОД картой, не на ней. Загрузка: `/tmp/dl_tarot_deck.py` (Commons API, ретраи+троттлинг 4с).

**Сделано и проверено в браузере:**
- `full_deck` отдаёт `img`-слаг карты (`tarot.py`): `m00..m21`, `wands01..14`, `cups01..14`, `swords01..14`, `pents01..14` — все 78 совпадают с файлами.
- Карточки расклада переписаны: `.tcard` с **реальной картинкой RWS** (лицо) и рубашкой `card-back.jpg`, описание (`tpos-desc`) под картой; компактная сетка `.tarot-grid` (auto-fill, мин. 108px), карты до 132px — крупнее, но расклад компактный.
- **Переворот без прыжка скролла:** `flipCard` теперь точечно переключает `.open` на карте (никакого полного `renderChat`) → `scrollJump = 0`.
- **Убрана кнопка «перетасовать»** (по решению пользователя) — удалены `redraw()` и case.
- **Выбор схемы компактен:** карусель показывает ровно **3 карты** + кнопка-стрелка «→» (`spreadNext`) + подсказка «листай вправо — ещё N схем»; убран список позиций и лишний заголовок — влезает в один экран.
- **Фон чата:** параллакс `.starfield` выключен при скролле ленты (фон не «плывёт»), добавлен лёгкий скримм `.chat-messages`.

```
    → Анимация «раздачи колоды»: карты по одной вылетают из стопки; выбор схемы — свайпаемые карточки с описанием, а не 3×3; премиум → мягкий модал «Как открыть»; «перетасовать заново».

[5] Инструменты в чате: луна · матрица · совместимость · история
    ⚠ B4 двойные fetch, B6 карта-гвард.
    → re-entry-гварды, единый виджет-паттерн «цифра → раскрытие», skeleton.

[6] Профиль и память
    ⚠ U1 пустые состояния слабые, C6 запросы порознь.
    → Promise.all, пустые состояния с CTA, «сбылось» на раскладах (POST /api/tarot/outcome/{id} готов).
```

**Вывод:** продукт теряет клиентку на самом входе (нет онбординга и вау) и на артефакте (наталку нельзя расшарить). Возвращаемость — карта дня (есть) + наталка (чиним) + стрик (греть). Виральность — рефералка и сторис (нет совсем). Ровно на этих четырёх осях строим v4.

## 4. Визуальная система «вау» — язык эффектов для каждого инструмента

Единая палитра Astral Midnight остаётся (ночь + золото + аметист). v4 добавляет **язык микровзаимодействий** — каждая вещь имеет состояние и анимацию:

| Элемент | Состояние → эффект | Реализация |
|---|---|---|
| Свайп экрана/чата | влево = назад / следующий | JS touch: `touchstart/move/end`, порог 50px, `translateX`-след + haptic |
| Таро «раздача колоды» | карты по одной вылетают из стопки (переворот + подъём) | staged `@keyframes` + `animation-delay: i*90ms`, `rotateY(90→0)` + `translateY(cardHeight)` |
| Выбор схемы расклада | свайпаемая карусель карточек с живьём-схемой | `.spread-swipe` (overflow-x + scroll-snap), карточка активна по центру |
| Наталка | «карта собирается»: дома появляются по кругу, затем планеты, затем аспекты | staged `fadeIn+scale` с задержками по массиву |
| Планета в SVG | hover/тап → тултип с планетным символом и градусом | `title`/`foreignObject`/плавающая подпись |
| Кнопки «в сторис» | золотой glow + лёгкий bounce при генерации | класс `.sharebtn` + `popIn` |
| Пузырь чата | свайп влево → раскрыть действия (коп-и юзер-телу) | touch + `.msg-actions` |
| Онбординг-интро | полноэкранный swipeable, кнопка «Начать ✨» lead в чат | 3 скринa, dots-прогресс, fade между |

**Правило reduced-motion:** все новые анимации идут под `@media (prefers-reduced-motion: reduce)` → заменяются кроссфейдом или disable.

## 8. Что НЕ делаем (YAGNI)
- **Не добавляем фреймворк/билд** — остаёмся vanilla JS + CSS (прод-CSP `style-src 'self'`, `@twa-dev/sdk` не нужен: авторизация серверная HMAC).
- **Не переносим шеринг в бэк (новая Pillow-отрисовка наталки)** — фронт SVG→canvas без зависимостей; используем готовый `share.py` для расклада.
- **Не делаем realtime/websocket-стриминг LLM** — ответ приходит целиком; стриминг — отдельная задача (не для «вау-вида»).
- **Не вводим сложный конфиг-флагов-билдер** — флаги читаем, кнопки прячем/показываем мягко.
- **Свайпы не насилуем**: сохраняем нижний бар как fallback доступности, жесты — первичны, но не единственный путь.
