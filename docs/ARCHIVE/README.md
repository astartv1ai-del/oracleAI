## Document orientation

| Field | Definition |
|---|---|
| **Purpose** | Retain useful superseded plans and design proposals without confusing them with current truth. |
| **Source of truth** | Current code and the canonical documents linked from [`../README.md`](../README.md). |
| **Scope** | Historical planning and design material with continuing context value. |
| **Do not change** | Do not implement from an archived proposal without creating or updating a current contract and acceptance tests. |
| **Key files** | The dated files in this directory and [`../RELEASE/TASKS.md`](../RELEASE/TASKS.md). |
| **Validation** | Compare any proposed work with current code, release status and the canonical map before use. |

Every document here is historical, date-labeled and superseded. The active backlog is [`../RELEASE/TASKS.md`](../RELEASE/TASKS.md); the active design contract is [`../DESIGN_SYSTEM.md`](../DESIGN_SYSTEM.md).
