# 🔮 Оракул — AI-астролог в Telegram

Бот + Mini App + панель управления полного цикла.

- **Шесть агентов** с памятью и 13 скиллами: Оракул (личный), Таролог, Астролог,
  Нумеролог, Наставница практик, Хранитель дневника. Расчёты делает код, модель
  только трактует — отсюда «правдивость», на которой держится доверие.
- **Астрология**: настоящая натальная карта (Swiss Ephemeris), транзиты, фаза
  Луны, лунный календарь, синастрия, деловые окна для карьерных решений.
- **Таро**: 78 карт, честный `secrets`-рандом, 9 раскладов, 3D-переворот
  с искрами, история с отметкой «сбылось».
- **Матрица Судьбы**: арканы, октаграмма, полный разбор.
- **Практики и мантры**: 12 программ (мантры, деньги, любовь, энергия) с шагами,
  программой по дням, стриком, напоминаниями и знаками продвижения.
- **Карьера**: расклады на карьеру и рабочие конфликты, разбор предназначения,
  деловые окна «когда действовать, когда молчать».
- **Гороскопы по 12 знакам** с автопостингом в каналы-спутники — бесплатный
  канал трафика.
- **Дневник** со стриком, вечерним вопросом от Оракула и месячным отчётом.
- **Монетизация**: триал 30 дней, подписки за Telegram Stars, web-оплата
  (Paddle) мимо комиссии сторов, Кристаллы ✦, одиночные расклады и разборы,
  промокоды-«золотые билеты».
- **Рост**: двухуровневая рефералка, картинки-карточки раскладов для сторис,
  PDF-разборы как товар для маркетплейсов.
- **Безопасность**: кризисный протокол (вопрос о жизни и насилии не доходит до
  модели и не тратит лимит), антифлуд, лимиты запросов, аудит админ-действий.
- **Наблюдаемость**: учёт токенов и себестоимости по каждому вызову LLM,
  воронка, когорты, каналы привлечения.

Проверка проекта одной командой:

```bash
python -m scripts.selfcheck
```

## Быстрый старт

```bash
cd oracle
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m app.bot.main
```

Бот работает сразу:
- **без ключей** — офлайн-режим (шаблонные мистические трактовки на реальных
  данных карты, Таро и Матрицы);
- **с ключом Claude или OpenAI** (любым) — полный агентный режим.

Провайдеры (`LLM_PROVIDER=auto`) выстраиваются в **цепочку отказоустойчивости**:
`custom → anthropic → openai` — упал основной, агент сам уходит на резервный,
в конце — офлайн-режим. `CUSTOM_LLM_BASE_URL` подключает любой
OpenAI-совместимый сервер (vLLM, LM Studio, Ollama serve).

OpenAI-совместимые серверы читаются **только потоком** (`stream=True`): многие
прокси и локальные раннеры отвечают SSE независимо от запроса, и при обычном
разборе `content` приходит пустым. Размышления reasoning-моделей
(`reasoning_content`) в ответ не попадают. Если модель не умеет tool-use,
включается pre-tool режим: скиллы выполняются заранее и подкладываются
в контекст.

Если тяжёлые библиотеки (kerykeion/geopy) не установились — бот не падает,
а работает в лайт-режиме астрологии (знак Солнца + Матрица + Таро).
Нужна **kerykeion 5.x**: на 4.x расчёт домов не соберётся.

## Mini App

```bash
uvicorn app.api.main:app --port 8080
```

Локальный просмотр: `http://localhost:8080/?dev_user=<твой_tg_id>`
(dev-режим включается флагом `DEV_MODE=1`; tg_id появится в БД после /start).

Семь экранов: **Сегодня** (прогноз, карта дня, фаза Луны, гороскоп знака,
картинка для сторис), **Чаты** (шесть агентов), **Таро** (тасовка, раздача,
3D-переворот, трактовка, история), **Карта** (натальное колесо, планеты по
домам, октаграмма Матрицы, спидометр любви, большие разборы), **Практики**
(программы по дням со стриком), **Дневник**, **Профиль** (лавка, рефералка,
память, настройки).

API повторяет правила бота: без активной подписки — `402`, сверх лимита — `429`.
Прогноз дня кешируется на сутки, поэтому бот и Mini App показывают один текст
и не оплачивают генерацию дважды.

⚠️ `DEV_MODE=1` пускает в API любого по `?dev_user=<id>` без подписи Telegram.
Перед публикацией на боевом сервере поставь `DEV_MODE=0`.

Чтобы Mini App открывался из Telegram, нужен https-адрес:

```bash
cloudflared tunnel --url http://localhost:8080
```

Полученный `https://….trycloudflare.com` вставь в `.env` → `WEBAPP_URL=`.
Постоянный вариант — VPS + домен, см. «Развёртывание».

## Товар для маркетплейсов: PDF-разборы

Канал продвижения без бюджета: покупательница берёт PDF на площадке, внутри
находит «золотой билет» — промокод на 30 дней VIP.

```bash
# один заказ
python -m scripts.gen_pdf --name Анна --date 21.06.1999 --time 14:30 --city Казань

# партия из выгрузки заказов
python -m scripts.gen_pdf --csv orders.csv --batch etsy-1
```

Каждому разбору выдаётся свой промокод и печатается внутри файла. Партия
(`--batch`) = листинг: по ней в панели видно, какой листинг приводит платящих.

Для PDF нужен WeasyPrint (`pip install weasyprint` + системные `libcairo2`,
`libpango-1.0-0`). Без него скрипт сохранит HTML и честно скажет об этом.

## Каналы-спутники с гороскопами

Двенадцать текстов в сутки на весь сервис (не по тексту на клиентку) собираются
планировщиком и публикуются по каналу на знак:

```
HOROSCOPE_CHANNELS=aries:@ora_aries,taurus:@ora_taurus,...
```

Автопостинг дополнительно включается флагом `horoscope_channels` в панели —
чтобы случайно не начать публиковать до готовности каналов.

## Структура

- `app/bot/` — aiogram: онбординг, чат, Таро, практики, карьера, профиль, Stars
- `app/core/` — агенты, астрология, Таро, Матрица, память, безопасность,
  практики, карточки
  - `core/safety.py` — кризисный протокол: решение принимает код, а не промпт
  - `core/memory.py` — дедупликация фактов по смыслу, поиск под вопрос, сводка
  - `core/stable.py` — устойчивый сид: встроенный `hash()` рандомизируется при
    каждом запуске Python, из-за чего карта дня и балл пары менялись после
    рестарта
- `app/api/` + `miniapp/` — FastAPI + Mini App
- `app/pdfgen/` — генератор PDF-разборов (товар для маркетплейсов)
- `admin/` — панель: CRM, каталог, контент, флаги, рассылки, аналитика, аудит
- `app/services/` — правила продукта: лимиты, деньги, чат, практики, гороскопы,
  планировщик
- БД: SQLite в `data/oracle.db` (создаётся сама, режим WAL)

## Развёртывание

```bash
docker compose -f infra/docker-compose.yml up -d --build
```

Процессов ровно два, и это принципиально: планировщик и рассылки живут **только**
в процессе бота — второй экземпляр отправил бы каждое сообщение дважды. API
масштабируется свободно. В комплекте — Caddy с автоматическим https, healthcheck
и ежедневный бэкап базы (`sqlite3 .backup`, хранение 14 дней).

Домен впиши в `infra/Caddyfile` и в `.env` → `WEBAPP_URL`.

## Безопасность

- Кризисный протокол (`app/core/safety.py`): сообщения о суициде, самоповреждении
  и насилии не доходят до модели — клиентка получает поддержку и контакты помощи,
  лимит не тратится. Контакты правятся в панели (`safety.helplines`).
- Подпись Telegram initData проверяется со сроком жизни 24 часа.
- Вебхуки платёжек: подпись по сырому телу + журнал `webhook_events` —
  повторная доставка не выдаёт подписку дважды.
- Данные рождения удаляются по команде /delete_me (анонимизация, финансовый
  след остаётся).
- Перед боевым запуском: `DEV_MODE=0`, свой `BOT_TOKEN`, заполненный `ADMIN_ID`.
