# 🔮 Оракул — личный AI-астролог в Telegram

Личный астролог, таролог, нумеролог, наставница практик и дневник — в одном чате. Расчёты делает код, модель их трактует: натальная карта по Swiss Ephemeris, честный случайный выбор карт Таро, Матрица Судьбы по формулам. Модель **не выдумывает** планеты и карты — отсюда «правдивость», на которой держится доверие.

Сервис полного цикла: Telegram-бот (aiogram) + Mini App (FastAPI) + админ-панель + каналы продвижения (гороскопы по знакам, PDF-разборы на маркетплейсах, рефералка). Для русскоязычных женщин 25–45, которые хотят не «гороскоп для всех», а личный проводник, который помнит именно её.

## Быстрый старт

```bash
cd oracle
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # BOT_TOKEN, ADMIN_ID, WEBAPP_URL
python -m app.bot.main      # бот
uvicorn app.api.main:app --port 8080   # API / Mini App
```

Бот работает сразу: без ключей — офлайн-режим на реальных расчётах; с ключом Claude/OpenAI/локального сервера — полный агентный режим с цепочкой провайдеров. Проверка проекта одной командой: `python -m scripts.selfcheck`.

## Ключевое

- **Шесть агентов**: Оракул (Лилит), Таролог, Астролог, Нумеролог, Наставница практик, Хранитель дневника — с памятью и 12 инструментами расчёта.
- **Астрология**: натальная карта, транзиты, фаза Луны, лунный календарь, синастрия, деловые окна.
- **Таро**: 78 карт, 9 раскладов, честный рандом, 3D-переворот, история с отметкой «сбылось».
- **Матрица Судьбы**, практики и мантры (12 программ со стриком), дневник, карьера.
- **Гороскопы по 12 знакам** с автопостингом в каналы-спутники — бесплатный канал трафика.
- **Монетизация**: триал 30 дней, подписки за Stars и web (Paddle), Кристаллы ✦, одиночные расклады, PDF-разборы.
- **Рост**: двухуровневая рефералка, карточки для сторис, SEO-лендинг.
- **Безопасность**: кризисный протокол, антифлуд, идемпотентные платежи, `/delete_me`;
  Mini App под строгим CSP без `unsafe-inline`: 0 inline-хендлеров (все действия на делегировании `data-act`),
  серверный текст экранируется белым списком `<b>/<i>`, шрифты селфхостятся в `miniapp/fonts/`, ассеты с cache-busting `?v=1`.

## Структура репозитория

- `app/bot/` — aiogram: онбординг, чаты, Таро, практики, профиль, оплата
- `app/core/` — агенты, расчёты (астрология/Таро/Матрица), память, безопасность, скиллы
- `app/api/` + `web/` — FastAPI, Mini App, лендинг, robots/sitemap
- `miniapp/` — Mini App (chat-first): `app.js`, `styles.css`, `fonts/` (самохостинг шрифтов)
- `app/services/` — правила продукта: лимиты, деньги, чат, практики, гороскопы, планировщик
- `app/repo/`, `app/data/` — SQL-слой, схема, миграции, сид каталога
- `app/pdfgen/` — PDF-разборы (товар для маркетплейсов)
- `admin/` — админ-панель: каталог, контент, флаги, рассылки, аналитика, аудит
- `infra/` — Docker, Caddy, бэкапы · `scripts/` — selfcheck, промокоды, PDF · `tests/` — pytest
- БД: SQLite в `data/oracle.db` (создаётся сама, режим WAL)

## Полезные команды

```bash
python -m scripts.selfcheck                 # проверка проекта
pytest tests/ -q                            # автотесты
python -m scripts.gen_promo 20 --days 30 --batch etsy-1   # промокоды
python -m scripts.gen_pdf --name Анна --date 21.06.1999 --time 14:30 --city Казань  # PDF-разбор
```

Деплой — `docker compose -f infra/docker-compose.yml up -d --build` (подробно в `docs/OPERATIONS.md`).
